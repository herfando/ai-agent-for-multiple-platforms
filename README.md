# AI Agent for Multiple Platforms

A multi-platform AI Agent designed to automate customer communication, engagement, and business workflows across multiple channels from a single intelligent system.

## Vision

Build one AI Agent capable of handling conversations, comments, direct messages, leads, and customer support across:

- Instagram
- WhatsApp
- Facebook
- Telegram
- Email
- TikTok
- Future communication channels

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS

### Backend

- FastAPI
- Python

### AI

- Groq
- LLM Models (DeepSeek, Qwen, Llama)

### Database

- PostgreSQL

### Infrastructure

- Docker
- Docker Compose
- AWS EC2 (Windows)

### Deployment

- Vercel (Frontend)
- AWS EC2 (Backend)
