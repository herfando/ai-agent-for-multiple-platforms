# Project Notes

## Start Backend

1. Activate venv
   source venv/Scripts/activate

2. Start Docker
   docker compose up -d

3. Run backend
   uvicorn main:app --reload

4. Swagger

http://localhost:8000/docs

## Stop Backend

1. Stop backend
   Ctrl + C

2. Stop Docker
   docker compose down
